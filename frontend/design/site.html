Sovereign = Local + Agentic + Inspectable

01

One coordinator, one policy boundary

Chat, Documents and Code are entry points into a single local harness. They do not keep separate identity, memory, routing or audit systems.

02

Capabilities arrive as packs

Enable document or code work and the installer will resolve the smallest model and tool plan for it, showing source, licence and size first.

03

Routing you can override

Each job keeps its model, its device and the reason on record. Automatic model choice is on the way; for now, you pick the model.

04

Every run is inspectable

Job state, tool calls, artifacts and approvals are recorded as events, so a run can be inspected after the fact.

Capabilities

Built for the work a plant actually generates.

Where Refinix is headed: approval notes, inspection reports, engineering calculations, internal tooling code, and drawings that arrive as scans.

01

Read what is on paper

Scanned reports, handwritten annotations, P&IDs and photographs, through on-device OCR and vision. Findings keep their page numbers, so a draft traces back to the sheet.

02

Ground it in your own manuals

A local retrieval connector over your SOPs, standards and past correspondence. Citations point at your own disks, and the index never leaves them.

03

Produce the actual deliverable

Approval notes, spreadsheets and decks that open correctly as .docx, .xlsx and .pptx, plus code changes validated in a sandbox with networking off.

04

Use the machines you have

One workstation is a complete installation. Pair a second trusted device and a vision job can run there while a coding job runs here. One job, one model, one device, never weights split across machines.

The evidence rule

A claim, an observation and a blank are three different things.

A green tick cannot tell you whether a control is running, or whether anyone was watching. So Refinix is designed never to draw one.

  1. Every figure names its source.
  2. A missing source stays visibly missing.
  3. No fourth state quietly means probably fine.
Enforced

A named control is active

For example: a host firewall ruleset is loaded and blocking, and the layer doing the enforcing is named beside the claim.

example · nftables inet/filter

Observed

A named observer saw a count

For example: zero public outbound flows, on stated interfaces, in a stated window. No observer and no window means no figure.

example · named observer, stated window

Unavailable

There is no evidence

For example: no observer installed on this host. Drawn as missing, never as a zero, because absence is not proof.

no source
