The evidence rule

A claim, an observation, and a blank are three different things.

Most tools show you a green tick. Refinix will not, because a green tick cannot tell you whether a control is running or whether anyone was watching. Every figure names its source, and a missing source stays visibly missing.

Enforced

A named control is active

The host firewall ruleset is loaded and blocking. The layer doing the enforcing is named alongside the claim, every time.

Observed

A named observer saw a count

Zero public outbound flows in a stated window, on stated interfaces. A count without an observer and a window is not published at all.

Unavailable

There is no evidence

No observer installed on this host. Shown as missing, never as a zero and never as green, because absence is not proof.

Design approach

Nothing leaves.Everything is recorded.

01

One coordinator, one policy boundary

Chat, Documents and Code are entry points into a single local harness. They do not keep separate identity, memory, routing or audit systems.

02

Capabilities arrive as packs

Enable document work or code work and the installer resolves the smallest model and tool plan for it, showing source, licence and size first.

03

Routing you can override

Auto picks a device from capability and health evidence. The chosen model, the device and the reason stay on screen, and you can overrule them.

04

Every run is replayable

Job state, tool calls, artifacts and approvals land on one append-only event stream, so a run can be inspected after the fact.

Capabilities

Built for the work a plant actually generates.

Approval notes, inspection reports, engineering calculations, internal tooling code, and drawings that arrive as scans rather than files.

01

Read what is on paper

Scanned inspection reports, handwritten annotations, P&IDs and photographs, through on-device OCR and vision models. Findings keep their page numbers, so every claim in a draft traces back to the sheet it came from.

02

Ground it in your own manuals

A local retrieval connector over your SOPs, standards and past correspondence. Citations point at documents on your own disks, and the index never leaves them.

03

Produce the actual deliverable

Approval notes, spreadsheets and decks that open correctly in the tools your organisation already uses — .docx, .xlsx, .pptx — plus code changes validated in a sandbox with networking switched off.

04

Use the machines you have

One workstation is a complete installation. Pair a second trusted device and the coordinator can route a vision job there while a coding job runs here. One job, one model, one device — never split weights across machines, so the audit trail stays simple enough to check.

Get started

Install it, then verify it.

Every build ships with a checksum and a signed manifest. Air-gapped sites install from verified removable media or an internal mirror — the installer never needs this website to reach the plant.
