Working in a project folder

Code will let Refinix read a project on this computer and propose changes to it.

It does not do that yet. Nothing on this computer can be read or edited from this screen, and no folder has been connected. Chat is the working surface today.

This screen exists so the destination is real and its state is honest, not so the feature can be implied.

Access modes

When Code arrives, you will choose how much it may do on its own. These are the planned modes, written down so the decision is visible early.

  • Partial access Safe, bounded actions happen automatically. Anything that changes a file asks you first.
  • Full access Workspace edits and project commands happen automatically. Destructive actions, installations and Git writes still ask you.
  • Ask before actions Nothing happens until you approve it.

There is deliberately no selector here. A control that looked like it set a permission would imply an enforcement that does not exist yet, and choosing a mode would change nothing. The selector arrives with the enforcement that backs it.
